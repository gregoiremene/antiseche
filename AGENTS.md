# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Le projet est volontairement en **SDK 54**, et il ne faut pas le remonter sans
vérifier d'abord la version d'Expo Go installée sur le téléphone de test
(Expo Go → Settings). Raison : le Play Store distribue Expo Go 54.0.8, qui ne
supporte que le SDK 54. Le SDK 57 (scaffold initial) et le SDK 56 ont tous deux
été rejetés par le client.

Avant tout changement de SDK : lire la version d'Expo Go, PAS l'inverse.
